# 课间 · 课程表 v4（iPhone PWA）

- 支持烟台大学 URP “选课结果” HTML 导入。
- 支持杭州医学院正方教务 “个人课表查询” HTML 导入，包括分段周次、单双周、同课程不同教师。
- 手机端紧凑布局：周一到周日横向完整显示，默认 1-12 节一屏可见；若导入学校存在 13 节以上，会自动扩展。
- “显示非本周课程”开启时，非本周课程透明度固定为 50%。
- 支持本机自定义课表背景。
- 支持本机自定义 iPhone 主屏幕图标；修改后需删除旧图标，再从 Safari 重新添加到主屏幕。
- 课程数据、背景和自定义图标均保存在当前设备浏览器，不会上传到 GitHub。
