# 课间 · 课程表 v5（iPhone PWA）

- 第一周周一默认设置为 **2026-08-31**。
- 支持烟台大学 URP “选课结果” HTML 导入。
- 支持杭州医学院正方教务 “个人课表查询” HTML 导入，包括分段周次、单双周、同课程不同教师。
- 手机端紧凑布局：周一到周日横向完整显示，默认 1-12 节一屏可见；若导入学校存在 13 节以上，会自动扩展。
- “显示非本周课程”开启时，非本周课程透明度固定为 50%。
- 支持本机自定义课表背景与 iPhone 主屏幕图标。
- 支持删除整个当前课表；若删除的是最后一张课表，会自动创建一张新的空课表。

## 隐私说明

**网站负责提供程序，课表数据只留在用户自己的设备里。**

教务系统 HTML 在当前浏览器本地读取和解析。课程、课表设置、背景图片和自定义图标不会因为使用本网站而自动上传到 GitHub 或其他服务器。只有用户主动生成并分享“同步码”时，对方才能通过该同步码获得其中包含的课表数据。
