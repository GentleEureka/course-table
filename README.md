# 课间 · 课程表 v3（iPhone PWA）

## 部署
把本文件夹中的所有文件保持原目录结构上传到一个 HTTPS 静态网站。
推荐 GitHub Pages、Cloudflare Pages、Netlify 等。网站入口必须是 `index.html`。

## iPhone 添加到主屏幕
1. 用 Safari 打开部署后的 HTTPS 地址。
2. 点 Safari 的“共享”。
3. 选择“添加到主屏幕”。
4. 如系统显示“作为网页 App 打开”，保持开启。
5. 点击“添加”。

## 数据说明
课程数据仍保存在浏览器的 localStorage 中，不会自动上传到服务器。
由于 `file://` 本地文件与 HTTPS 网站属于不同存储来源，从 v2 本地文件切换到部署后的 v3 时，原课程数据不会自动迁移。可以重新导入教务 HTML，或先在旧版生成同步码，再在 v3 导入同步码。

## 隐私
只部署程序文件。不要把包含姓名、学号、选课信息的“选课结果.html”一起上传到公开网站。
